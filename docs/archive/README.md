# Archives documentaires

Ce dossier regroupe les notes internes, documents historiques, audits ponctuels et materiaux de travail qui ne font pas partie de la documentation canonique.

Regles :

- ces fichiers peuvent etre utiles au mainteneur
- ils ne doivent pas etre utilises comme source de verite fonctionnelle
- toute information encore utile au produit ou au code doit etre remontee dans `wiki/` ou `docs/`
